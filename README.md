# LoveMarkdown

Free online Markdown converter — convert Markdown to PDF, Word, HTML, LaTeX, Confluence, Image and more.

🌐 **Live site:** [lovemarkdown.com](https://lovemarkdown.com)

## Features

- **Markdown → PDF** — Custom styles, fonts & page size
- **Markdown → Word** — Export to .docx for Word & Google Docs
- **Markdown → HTML** — Clean HTML with syntax highlighting
- **Markdown → LaTeX** — Academic papers & thesis writing
- **Markdown → Confluence** — Confluence wiki markup for Atlassian
- **Markdown → Image** — PNG/JPEG with frame styles for social media
- **Markdown → Google Docs** — Rich text for Google Docs

All conversions happen in your browser — your files never leave your device.

## Tech Stack

- [Next.js](https://nextjs.org) 16
- [Tailwind CSS](https://tailwindcss.com) 4
- [Cloudflare Workers](https://workers.cloudflare.com) (deployment)
- [OpenNext](https://open-next.js.org) (serverless adapter)

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Build for Cloudflare Workers
npm run build-cf

# Deploy to Cloudflare Workers
npm run deploy
```
